# 鄉村 / 城市 段落分類：以《邊城》與《駱駝祥子》為例

## 1. 研究問題

中文小說段落的敘事空間能否用詞袋模型區分為「鄉村」與「城市」兩類？本報告以《邊城》（鄉村）與《駱駝祥子》（城市）為語料，在段落層級訓練 LogisticRegression 分類器。

## 2. 資料與標註

- 語料：《邊城》《駱駝祥子》
- 文本單位：切分段（去 BOM → 空行分塊 → 句末切句 → 貪心合併），長度 50–400 字
- 標註總數：284（鄉村 142 / 城市 142）
- 標註方式：按書名打標（《邊城》=鄉村、《駱駝祥子》=城市）；另設 `human_overrides.csv` 人工校正機制（改標/剔除後重跑 02 重新平衡）
- 類別平衡：對較大一類下採樣至 1:1

## 3. 方法

- 分詞：jieba，過濾單字
- 特徵：詞頻 top-200 / 詞級 TF-IDF(1,2) / 字符級 TF-IDF(2,3)
- 分類器：LogisticRegression（liblinear, class_weight=balanced）
- 切分：80/20 分層抽樣，random_state=42

## 5. 核心局限

兩部小說、兩位作者、兩個標籤完全共線。模型學到的可能是「沈從文文體 vs 老舍文體」，而非「鄉村敘事 vs 城市敘事」。報告須以此為核心局限討論，並建議未來引入同作者內部的城鄉對照段落來解耦。
